Run `node skills/development/languages/zig/scripts/verify-official-release.mjs --check --verify-links`. The script reads Zig's official `download/index.json`, excludes master/development builds, selects the latest stable release by semantic version, and verifies the version's docs, stdDocs, and notes/release notes metadata and links.

At query time, a passing result proves only the official index structure, latest-stable selection, and reachability of versioned links. It cannot prove that future versions will remain the same or that any local toolchain, project build, target, or runtime behavior is correct.
