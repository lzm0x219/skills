`unreachable` is inappropriate for an unknown tag in user input or other external input. Model it as an ordinary error or error union, and use `unreachable` only for a proven invariant.

Do not set `@setRuntimeSafety(false)` across the entire module. Establish a benchmark and profile first to confirm that safety checks are a measured bottleneck. If disabling them has a real benefit, narrow it to the smallest scope protected by explicit preconditions and tests. Verification must cover a mode with runtime safety enabled and the ReleaseFast, ReleaseSmall, or other optimization modes actually supported by the project, recording the behavior for invalid input.
