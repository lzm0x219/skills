`minimum_zig_version = 0.15.2` is only the minimum supported lower bound, not the sole version or an exact pin. Preserve the CI-supported range of 0.15.2 and 0.16.0. Select an explicit active compiler for each verification run, and run builds and tests on at least the minimum supported release and the latest stable release within the range.
