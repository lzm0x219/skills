`minimum_zig_version = 0.15.2` 只表示最低支持下限，不是唯一或精确固定版本。保留 CI 的 0.15.2 与 0.16.0 支持范围；每次验证选择明确的当前执行编译器，并至少在最低支持版和范围内最新稳定版运行构建与测试。

仓库没有单独指定格式化器时，先用当前验证编译器运行 `zig fmt --check`；若 0.15.2 和 0.16.0 产生不同格式，停止自动改写并确定仓库的格式化器版本。语法、Style Guide、标准库、Build API 和 release notes 分别使用对应版本的版本化文档，不能用 0.16.0 文档证明 0.15.2 可用。
