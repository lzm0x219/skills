## 交付原则

「电商素材包」是本 Skill 的完整主交付，不是把若干文件临时装进一个文件夹。

- **品牌方决策包**以商品销售战略报告为判断母稿；PDF 是它的分享阅读版，不另写第二套内容。
- **商品页成交包**以商详方案建立成交路径；保留多方案和最终定稿，并将确认的文字落实为逐屏视觉资产。
- **多渠道传播包**从同一战略母稿派生渠道化表达，不得改写产品事实和价格条件。
- `internal/` 保存给下游 Agent 使用的结构化中间件，不对客户报告暴露方法来源。

## 战略报告 PDF

完成 `商品销售战略报告.md` 后，先读取 [pdf-style.md](pdf-style.md)，再使用 `scripts/md_to_pdf.py` 导出同目录 PDF：

```bash
python3 scripts/md_to_pdf.py \
  "01-品牌方决策/商品销售战略报告.md" \
  "01-品牌方决策/商品销售战略报告.pdf" \
  --date YYYY-MM-DD
```

要求：

- PDF 面向品牌方、渠道方或合作伙伴阅读，隐藏 YAML frontmatter、内部路径和方法来源；
- 使用「封面 → 阅读导航 → 结论摘要 → 分页章节 → 最终决策卡 → 主要来源」的报告级结构；
- 保留标题层级、表格、列表、引用和链接；传播钩子中的引用标题不得误判为章节；
- A4 竖版、纯白纸面、黑白冷灰层级、决策轨道和横线表格，正文适合屏幕和打印阅读；
- 来源附录使用中性低强调层级，每条网络来源同时显示来源名称、完整 URL 和可点击链接；
- 末尾固定保留 `本报告由 china-commerce-asset-pack Skill 协助生成`；用户指定封面报告署名时另传 `--author`，不得伪造第三方署名；
- 输出 PDF 已存在时默认停止；只有用户明确同意替换后才传 `--overwrite`；
- Markdown 更新后必须重新导出 PDF，避免双版本内容漂移；
- 导出后用 `pdfinfo` 检查页数，用 `pdftoppm` 渲染全部页面为 PNG；逐页检查中文、表格、分页、页码、链接文字、孤行和溢出；
- 再用 `pypdf` 或 `pdfplumber` 抽取文本，抽查标题、人民币价格、SKU 和关键结论是否存在。

Chrome 是默认和规范渲染器，`auto` 不切换到其他引擎；Chrome 路径可通过 `--chrome` 或 `CHINA_COMMERCE_ASSET_PACK_CHROME` 指定。只有明确需要可选引擎并安装对应依赖时，才传 `--engine weasyprint`。不要以未经目视检查的系统打印 PDF 作为最终交付。

> 建议零售价：

## 一、快速使用

[先看什么、直接可用什么、哪些地方需要替换]

## 二、交付文件

| 模块 | 文件／目录 | 状态 | 用途 | 使用前注意 |
| ---- | ---------- | ---- | ---- | ---------- |

## 三、发布建议

[推荐发布顺序、素材复用关系、首轮测试]

## 部分交付

用户只要求战略、商详、图片或社媒其中一部分时：

- 只生成该阶段必要文件，不制造空壳；
- 仍使用一致的编号和命名，便于未来追加；
- 在总清单或当前阶段说明中标记范围；
- 若只做社媒素材，先建立最小 `internal/messaging-matrix.md`，避免无战略依据地批量写稿。

## 版本变更与恢复

在总清单记录本轮版本和每项交付的上游来源版本（战略、文案或视觉母版），并使用「待制作／待检查／已通过／已失效／受阻」区分状态。只有实际存在且通过对应检查的文件才算交付。

用户改价、改 SKU、改活动或改定稿后，先更新事实台账与受影响的母稿，再按依赖标记旧资产失效：

- 价格与活动变化：检查战略摘要、最终商详、含价图片、渠道文案、CTA 和清单；
- 包装或规格变化：检查所有商品图、标签、规格表及含该事实的文案；
- Markdown 变化：其分享版 PDF 失效；视觉母版变化：依赖它的系列图需重新检查。

只重做受影响资产，保留无关且仍有效的成品；变更范围内复用已有制作授权。未授权替换既有文件时写入新版本路径，旧版保留但从当前交付清单撤下。仅替换文字文件名、修改清单日期或更新 Markdown，不会同步修复图片和 PDF。

中断后先检查已有文件、对应提示词／上游版本与 QA 记录。缺文件的工具成功消息不算交付；已保存但未检查的成图先验收；已通过且来源仍有效的图片直接复用，只补缺失、失效或失败项。恢复不隐含发布授权。

## 最终验收

- 目录编号、文件名和清单完全对应；
- Markdown 与 PDF 版本、日期和内容一致；
- 当前清单不含已失效或仅有工具成功消息而无实际文件的资产；
- 商详文字与商详图片逐页对应；
- 社媒文案与配图按角度或编号对应；
- 所有对外材料中的品牌名、SKU、规格、价格、活动、CTA 和链接一致；
- 未经确认的促销条件、用户评价、功效和机构背书没有被写成事实；
- 所有占位符集中列出，没有散落的 `TBD`、示例链接或假二维码；
- 对外文件不含内部推理、方法来源、Agent 指令或本地绝对路径。
