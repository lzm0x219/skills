# 商品销售战略报告 PDF 版式规范

本文件只规定「商品销售战略报告.md」的分享版 PDF。内容仍以 Markdown 为唯一母稿；PDF 不另写、不删改结论，也不暴露内部方法、Agent 指令或方法来源。

## 版式目标

PDF 面向品牌方、渠道方和合作伙伴阅读，应让人先看懂结论与决策，再查阅分析过程。它是一份正式商业报告，不是 Markdown 的逐行打印版，也不是商详长图。

视觉基准：

- A4 竖版、纯白纸面和六列逻辑网格；
- 黑、白、冷灰构成主视觉，只用极浅云蓝区分结论摘要中的证据区域；
- 有封面、阅读导航、章节分页、页眉和页码；
- 中文正文使用系统提供且许可明确的 CJK 无衬线字体；
- 表格使用横线分隔，不使用密集全框线；
- 重点判断通过黑白反差、字重和空间表达，不滥用彩色底块；
- 宽表格自动缩小字号和单元格留白，但不得裁切、重叠或横向溢出。

贯穿全篇使用「决策轨道」：封面建立任务，阅读导航说明判断顺序，结论摘要集中主要建议，正文章节提供证据，最终决策页把建议转成条件、风险和行动。轨道必须编码真实阅读顺序，不能成为无意义装饰。

## 设计系统来源与边界

采用「Apple 的信息纪律、OpenAI 的编辑气质」：

- 参考 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) 的 hierarchy、harmony 和 consistency，把最重要的信息放在阅读顺序前端，并以对齐、空间和有限字重建立层级；
- 参考 [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography) 控制字体数量，使用清晰字号阶梯和可读字重；
- 参考 [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 通过稳定网格、分组和负空间表达信息关系；
- 参考 [OpenAI Design Guidelines](https://openai.com/brand/) 明确公开的几何精度、人文温度、清晰留白和标识使用边界；黑白编辑感、大字号与柔和色面仅作为其公开案例的视觉观察，不写成官方版式规范。

这些公开规范主要服务 UI 或品牌资产，不能直接作为第三方报告模板。只转译内容优先、层级、排版、留白、对齐、克制用色和几何原则；不使用 Apple／OpenAI 的 Logo、专有字体、图标、Design Resources、Blossom 或相似标识，也不暗示报告由两家公司制作、认可或合作发布。研究依据和可移植边界记录在仓库的 `docs/research/apple-openai-pdf-design-primary-sources.md`。

## 设计 token

所有样式先选择语义 token，再映射为具体数值。渲染实现应集中维护 token，避免在组件中散落近似颜色和任意间距。

| 类型 | Token                  |                       默认值 | 用途                           |
| ---- | ---------------------- | ---------------------------: | ------------------------------ |
| 颜色 | `page`                 |                    `#FFFFFF` | 纸张背景                       |
| 颜色 | `ink`                  |                    `#111111` | 标题、重点数字和决策轨道       |
| 颜色 | `text-body`            |                    `#2C2C2E` | 正文                           |
| 颜色 | `text-secondary`       |                    `#48484A` | 副标题、元信息                 |
| 颜色 | `text-muted`           |                    `#636366` | 页眉、页码、辅助说明           |
| 颜色 | `surface`              |                    `#F5F5F7` | 普通判断卡、代码块             |
| 颜色 | `surface-cool`         |                    `#EDF2F4` | 摘要页的单一柔和证据面         |
| 颜色 | `border`               |                    `#D1D1D6` | 中性分隔线                     |
| 颜色 | `border-strong`        |                    `#8E8E93` | 表格收尾与附录分隔线           |
| 间距 | `space-1` 至 `space-6` | `2 / 4 / 6 / 10 / 16 / 24mm` | 页内留白、组件内边距与章节节奏 |
| 字号 | `type-caption`         |                      `8.6pt` | 页眉、页码、辅助说明的最小字号 |
| 字号 | `type-source`          |                      `9.2pt` | 来源、表格正文                 |
| 字号 | `type-body`            |                     `10.8pt` | 正文                           |
| 字号 | `type-h3 / h2 / h1`    |             `12 / 16 / 30pt` | 章节层级                       |
| 字号 | `type-display`         |                       `42pt` | 封面标题                       |

普通文字与背景对比度至少为 4.5:1；大号粗体文字和具有信息意义的图形至少为 3:1。黑白层级是主要编码，云蓝只承担摘要分组，结论、风险和状态还必须通过文字、字重、边框或位置表达。页眉、表格和来源附录不得小于 8.6pt。

## 文档结构

渲染器应按以下顺序组织页面：

1. 封面：报告标题、副标题、分析对象、市场、渠道、本轮目标、日期和可选署名；
2. 阅读导航：只列读者可见的一级阶段和开头的结论摘要；
3. 结论摘要：直接进入主要决策；
4. 正文章节：每个一级阶段从新页开始；
5. 最终决策卡；
6. 主要资料来源；
7. 工具生成说明。

Markdown 中位于第一条 H1 后的连续引用块视作封面元信息，不在正文重复。引用块中的 `> # 钩子` 只是传播主张，不得被误判为一级章节或加入阅读导航。

## 页面模板

每页应属于以下一种模板，避免逐段临时设计：

1. **封面**：只承担识别，不堆叠结论、图表或装饰；
2. **阅读导航**：说明阅读顺序并列出可见章节；
3. **结论摘要**：前置主推 SKU、核心顾客、核心主张、价格和下一步决策；
4. **标准章节**：标题、简短导语、分析或数据表、阶段判断；
5. **密集数据页**：优先保证列名、单位、比较基准和数据可读性；
6. **最终决策卡**：集中呈现建议、条件、风险和需要确认的事项；
7. **来源附录**：降低视觉权重，但保留完整名称、URL 和可点击链接。

封面和阅读导航使用黑色纵向决策轨道与非对称留白；结论摘要使用窄轨道和浅云蓝证据面；标准章节回到纯白纸面；最终决策采用黑色标题轨道与白色决策正文的双栏构图。相同任务区域内不得混用多套层级。

## 字体与节奏

- 正文约 10.8pt，行距约 1.8；
- H1 约 30pt，使用黑色大标题、细横线和小号证据序号；
- H2 约 16pt，使用字重和上下留白建立层级；
- H3 约 12pt，使用中号字重区分；
- 正文页左右留白约 22—25mm；
- 段前段后保持稳定，不通过连续空行制造版面；
- 标题与紧随其后的正文或表格尽量同页；正文避免单行悬挂。

正文统一左对齐；不得通过过度字间距换取齐边。长段落不居中，小号英文标签只标识页面职责，不代替中文信息。数字使用等宽数字字形，金额、比例、数量和日期在同一列保持格式一致。

## 表格

表格是商品战略报告的主要信息载体，必须优先保证可读性：

- 表头顶部使用黑色细线，底部使用中性灰细线；
- 正文行只保留浅灰横向分隔线；
- 表头跨页重复；完整数据行尽量不跨页；
- 1—4 列使用标准字号；5 列及以上自动进入紧凑模式；
- 不能为了塞进一页把所有表格统一缩成极小字号；
- 长表允许自然跨页，不能截图后缩放塞入 PDF。

数据表达同时遵守：

- 表题或上下文必须说明单位、统计口径和比较基准；
- 纯数字、金额和比例列右对齐，文本列左对齐；无法可靠识别数据类型时保持左对齐，不猜测；
- 同列的小数位、人民币符号、百分号和日期格式保持一致；
- 只强调推动决策的数据，不用装饰性色阶制造热闹；
- 图表优先直接标注数据系列；确需图例时使用清晰中文，并保证黑白打印仍可区分；
- 颜色不得作为唯一编码，同时使用标签、形状、线型或文字说明。

## 印刷与无障碍

- 白色与浅灰背景上的普通文字达到 4.5:1；浅云蓝只作为区域背景，不承担正文颜色；
- 页眉、页码、来源 URL 和六列以上紧凑表格仍不得低于 8.6pt；
- 以灰度预览检查标题、边框、表头和判断卡，信息层级不能依赖彩色打印；
- 链接文字显示可理解的来源名称，来源附录再显示完整 URL；
- 图片应有相邻标题或说明，关键结论不能只存在于图片；
- PDF 文本必须可抽取，标题层级和阅读顺序应与视觉顺序一致。

## 来源附录

- 「主要资料来源」属于附录，不沿用正文一级章节的大字号强调；
- 附录主标题改用较小的中性灰标题，分组标题不加色块和左侧色条；
- 每条网络来源同时显示来源名称和完整 URL；来源名称与 URL 均应可点击；
- URL 使用较小的中性灰字号，允许自然换行，但不得裁切；
- 本地材料只显示材料名称，不把本地绝对路径印在对外 PDF 中。

## 封面与署名

- 默认副标题为「中国市场新品销售策略」；
- 封面默认只显示生成日期，用户指定报告署名时再使用 `--author`；
- 报告末尾固定保留工具生成说明：`本报告由 china-commerce-asset-pack Skill 协助生成`；
- 使用者通过 `--author` 指定的报告署名显示在封面，不得伪造客户、机构或第三方署名；
- 对外 PDF 不出现外部方法来源、内部工作过程或本地绝对路径。

## 渲染命令

```bash
python3 scripts/md_to_pdf.py \
  "01-品牌方决策/商品销售战略报告.md" \
  "01-品牌方决策/商品销售战略报告.pdf" \
  --date YYYY-MM-DD
```

输出文件已存在时默认停止；只有用户明确同意替换后才传 `--overwrite`。

可选参数：

- `--title`：覆盖封面标题；
- `--subtitle`：覆盖封面副标题；
- `--author`：添加报告署名；
- `--overwrite`：允许替换已存在的输出 PDF；
- `--engine chrome|weasyprint|auto`：指定渲染引擎；`auto` 与 `chrome` 均使用规范 Chrome 引擎，`weasyprint` 仅显式启用；
- `--chrome /path/to/Chrome`：指定 Chrome／Chromium；
- `--html-output`：保留用于排查的中间 HTML；若报告含本地图片，同时保留 HTML 引用的私有图片快照；
- `--keep-html`：保留临时 HTML；若报告含本地图片，同时保留 HTML 引用的私有图片快照。

默认只使用 Chrome，不因机器环境不同自动切换排版引擎。Chrome 可通过 macOS、Linux 和 Windows 的常见安装位置自动发现，也可以用 `CHINA_COMMERCE_ASSET_PACK_CHROME` 指定。只有明确接受不同排版结果并安装 `requirements-weasyprint.txt` 后，才传 `--engine weasyprint`。

Chrome helper 使用一次性隔离环境；macOS 下启用 mock keychain，Linux 下使用基础密码存储，渲染不应请求浏览器密码或系统钥匙串权限。若仍出现权限窗口，停止批量渲染并报告受管浏览器策略或本机浏览器异常，不要要求用户输入钥匙串密码。报告内的 PNG、JPEG 和 WebP 会先验证并复制到私有资源快照；Chrome 与显式 WeasyPrint 都只读取该快照。WeasyPrint 在带超时的一次性子进程中运行。

报告正文只允许带主机名的 `https:` 链接和非空页内锚点。空链接、相对文档链接、仅查询参数链接及其他 scheme 可能暴露本地路径或产生不可控跳转，必须在渲染前改写或移除。

## 交付前目视检查

PDF 生成成功不代表验收通过。必须：

1. 用 `pdfinfo` 确认 A4、页数和文件非空；
2. 用 `pdftoppm` 把全部页面渲染为图片；
3. 先看全页缩略图，检查空白页、章节节奏和异常分页；
4. 再按原尺寸检查封面、阅读导航、最宽表格、引用卡、最终决策卡、来源页与工具生成说明；
5. 用 `pypdf` 或 `pdfplumber` 抽取文本，抽查标题、主推 SKU、建议零售价和核心主张；
6. 检查所有网络来源既显示 URL 又保留 PDF 点击链接；
7. 转为灰度缩略图，确认标题、表格、判断卡和链接仍可识别；
8. 抽查正文、小字和强调文字对比度，确认普通文字至少 4.5:1；
9. 若发现封面多出一页、引用钩子被当成章节、宽表裁切、附录过度强调、标题孤立、签名遗漏或页码缺失，修正样式后重新渲染全部页面。
