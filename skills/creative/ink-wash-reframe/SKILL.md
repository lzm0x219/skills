# 米白水墨扁平重构

将用户有权使用的参考图，转为结构更简洁、留白更克制的图文插画。保留的是可观察到的题材、主次关系、构图比例、整体色彩调性与支撑识别的中层细节；不是复制原图的笔触细节、签名或作者识别特征。

只在用户显式调用 `$ink-wash-reframe` 时执行本 Skill。

## 开始前

1. 必须查看实际参考图。网页链接无法读取清晰画面、只有口头描述或只给风格文案时，说明缺少参考图；可以给可填模板，但不得声称已完成“根据原图”的重构。
2. 提取一张**画面取证卡**：原始比例、主体与主次关系、主体位置、远近层次、2–4 个 **P0 核心结构**、0–5 个 **P1 识别细节**、2–5 个综合色组、**P2 可删项**，以及文字的确切内容或 `none`。P0 是缺失后场景会变样的结构；P1 是支撑识别的中层细节；P2 仅包含未列入 P0/P1 的微纹理、杂物和厚重光影。除非数量本身有识别意义，不要把普通细节强行编成精确数量。
3. 用户只要方案或提示词时，不生成图片。需要生成但没有可用图像工具时，交付可执行提示词和工具阻塞，不虚构图片或路径。
4. 用户没有给出英文标题和短句时，不编造英文标题。用 `text_area` 决定版面：两段精确英文都已提供时，默认 `reserved`；用户明确要求预留排版区时用 `reserved`；用户明确要把文字叠入现有留白时用 `overlay`；其余情况默认 `none`，只生成无字底图，不额外切出底部文字带。
5. 参考图来自第三方、公开账号或品牌时，不要保留或复刻签名、水印、Logo、可识别角色或受保护的独特表达。公开发布或商业使用前，提醒用户确认参考图与改编链路的权利；不得作出清权、原创或商用安全承诺。

## 重构流程

### 1. 固定不能漂移的画面事实

先用画面取证卡约束比例、主体关系、空间层次、P0 核心结构与综合色组。P0 必须完整保留；P1 必须逐项可辨，例如屋檐节奏、门框与台阶、桥面砌块分组或水面的主要倒影带。P1 可改为低对比小块面、断续淡墨或不规则色组，不能因“简化”被抹成单一轮廓。P2 才可删去枝叶、路牌、人流、随机反光和噪点，但不要把建筑、山水、道路或水面等 P0 结构换成无关场景。

### 2. 先完成无字底图

读取 [提示词与质检模板](references/prompt-and-qa.md)，将事实卡填入“无字底图模板”。其硬约束是：

- 画面只组织为三层：米白哑光纸底、承载 P0 的平涂色块、少量淡墨氛围层。淡墨用于空气感和层次，不堆成水彩式密纹。
- P0 可在必要的遮挡或接触处使用局部轻边界；P1 不得用连续深色闭合线围住物体，优先用色差、留纸、低对比小块面和断续淡墨区分。禁止把所有物体普遍描边。
- 不使用写实厚光影、P2 之外的密集微纹理、杂物或装饰边框；轮廓可松散，但 P0 与 P1 都必须可辨。
- 主体位于居中偏上。`reserved` 时保留干净、低对比、无物体遮挡的文字安全区；`overlay` 时只在已有安静留白中排版且不压住 P0/P1；`none` 时不人为保留底部安全带。留白是构图的一部分，而不是背景空缺。
- 依参考图的综合色组建立调色，而不是强行套用青绿、黑白或“国风”符号。

### 3. 以可验证方式加入文字

对要逐字正确的标题，采用**无字底图 → 后期排版 → 逐字核对**。后期排版时，首行使用用户已授权或可用的优雅衬线/手写感英文字体，第二行使用小号无衬线英文短句；`reserved` 放在预留区，`overlay` 放在确认过的现有留白。没有用户提供的文案时保持无字，不用占位乱码。

若用户坚持在图像生成阶段直接出字，先明确这不能保证拼写；输出后逐字检查，错字、乱码、文字遮挡或缺字即退回无字底图再排版。

### 4. 质检与单变量返工

按模板的 QA 门槛检查。一次返工只改一个失败项：P0 失真时回到事实卡；P1 丢失时只补回缺项，并保持低对比块面或松散墨痕；边线太硬时只移除 P1 的连续深色闭合线；文字区挤压画面时重选 `text_area`；文字错误时回到无字底图。未实际查看、生成或检查的部分必须如实标为未验证。

## 交付

交付提示词、画面取证卡、文字排版规格和 QA 结果；已生成时再报告实际文件路径与所用工具。不要覆盖已有资产，除非用户明确要求替换。

## 任务边界

- 适合旅行照片、风景、建筑、静物和轻叙事照片的克制水墨图文重构。
- 不用于需要精确尺寸、可编辑节点与连线的工程图、信息图，或要求复刻某位作者、品牌/IP、现有作品的独特画面。
- 不把“水墨”“学术感”误解为添加印章、诗句、题跋、书法、边框或泛化中国元素；除非用户明确提供并允许这些内容。
