# 卷卷正文配图

## 核心目标

把正文中的一个判断、过程、状态或隐喻，转成卷卷亲自参与的 16:9 怀旧手绘插图。让图片帮助读者理解或感受正文，不要把正文压缩成 PPT 信息图，也不要只把卷卷放在角落当装饰。

只在用户显式调用 `$juanjuan-illustrations` 时执行本 Skill。

## 开始前

1. 始终读取 `references/character-dna.md`，并查看 `assets/juanjuan-character-reference-v3.png`。
2. 规划构图时读取 `references/style-dna.md` 和 `references/composition-patterns.md`。
3. 生成或编辑图片时再读取 `references/prompt-template.md` 和 `references/qa-checklist.md`。
4. 用户只要求规划时，只输出 shot list；不得生成图片。
5. 用户要求公开发布、商业授权或商品制作时，先说明当前参考图仅用于内部视觉验证，最终母版与商用权利仍待确认；不得声称角色已原创登记、已清权或可安全商用。
6. 没有可用图像生成或编辑工具时，输出可直接执行的逐图提示词和明确的工具阻塞，不要声称已经生成图片。

## 工作流

### 1. 确定任务模式与数量

按以下优先级决定输出，不自行扩大数量：

1. 用户指定数量时，严格执行该数量。
2. 用户说“一张”“单图”时，只处理一个核心认知锚点。
3. 长文要求直接生成、但没有指定数量时，默认生成一张最能代表全文核心判断的图片，并说明选取的锚点。
4. 长文只要求规划、但没有指定数量时，默认规划 4–6 张；短文规划 1–3 张，长文通常不超过 8 张。
5. 用户要求规划时，等待确认后再生成；用户已经明确要求直接生成时，不额外停下来等待确认。

### 2. 建立来源事实卡

从用户提供的正文、文件、页面或截图中提取：

```text
core_claim: 本图唯一要表达的原文判断
exact_terms: 必须原样保留的术语
required_relationships: 必须画对的关系、方向、先后或对应
required_counts: 必须画对的数量；没有则写 none
unsupported_inferences: 原文没有支持、不得补写的含义
script: traditional | simplified | mixed | none
allowed_labels: 允许出现在图中的 0–5 个精确短词
```

专业、历史或方法论内容必须先完成来源事实卡。保留原文繁简体和术语，不凭常识补充正文没有表达的关系。来源事实卡与原文冲突时，以原文为准并重做事实卡。

### 3. 规划画面

读取 `references/composition-patterns.md`，把抽象概念转成卷卷必须亲自完成的物理动作。每张图只保留一个认知锚点。

规划模式输出 shot list，每张写清：

- 放置位置
- 核心意思
- 来源事实卡摘要
- 结构类型
- 卷卷动作
- 必须满足的接触、数量与路径
- 建议元素
- 精确短标注

### 4. 逐张生成

一次处理一张图：

1. 把 `assets/juanjuan-character-reference-v3.png` 作为身份、服装、配色、比例和媒介参考。
2. 按 `references/prompt-template.md` 注入来源事实卡、角色身份块和可验证约束。
3. 让卷卷亲自操作、经历、承受或改变核心隐喻；指定的手脚必须真正接触对应物件。
4. 严格满足物件数量、对应关系、方向和可追踪路径。
5. 默认采用单一物理场景、非对称景深和一个焦点动作。除非用户明确要求，不使用左—中—右讲解板、卡片网格或规整流程图。
6. 默认使用接近 16:9 的横版、暖奶油纸面、石墨和彩铅线条、蜡笔与淡水彩铺色。
7. 中文只使用来源事实卡中的 `allowed_labels`，不得增加标题、解释文字或其他字符。
8. 文字准确性关键时，先生成无字底图，再局部加入白名单文字并逐字核对。

### 5. 检查与迭代

按 `references/qa-checklist.md` 逐项比较来源事实卡、最终提示词与图片。以下情况视为失败，不以“意思大致成立”放行：

- 指定动作被简化成站立、指向或拿着道具
- 肢体没有接触指定物件
- 数量、对应、方向或路径不正确
- 出现白名单之外的文字，或繁简体、术语、字形错误
- 技术概念退化成 PPT、教学板或装饰性信息图

身份明显漂移时，从角色参考图重新生成整张；少量错字可局部编辑，错误较多时回到无字底图。

### 6. 保存交付

在 workspace 内工作时，默认保存到：

```text
assets/<article-slug>-juanjuan-illustrations/
```

按正文顺序保存图片及同名记录：

```text
01-topic-name.png
01-topic-name.prompt.md
```

`.prompt.md` 必须记录：来源锚点、来源事实卡、最终提示词、参考图相对路径、图像工具与模式、QA 结果、迭代记录和最终图片路径。

保存后运行确定性产物校验：

```sh
python3 <skill-directory>/scripts/validate_artifact.py <image-path>
```

只有脚本退出码为 0，并且 `references/qa-checklist.md` 的视觉硬门槛全部通过，才报告为最终交付。该脚本只检查 PNG、比例与记录契约，不代替视觉判断。

不要覆盖已有文件，除非用户明确要求替换。最终报告每张图的用途和绝对路径；未实际生成时只报告规划或提示词，不虚构文件。

## 任务边界

- 适合中文正文配图、情绪概念图、轻量流程隐喻、状态对比和已有卷卷图片的局部编辑。
- 不用于要求严格节点、连线和可编辑源文件的架构图、工程图或复杂流程图。
- 不用于未经确认的商业品牌 KV、商品母版或法律意义上的原创与权利清证明。
- “开放身份”只表示不声明现实年龄或固定性别；当前角色保留明显的内在小孩式绘本气质，不要宣称视觉上完全中性。
- 不因绘本气质把内容自动改写成儿童受众、卖萌或强行治愈。
