# 生成后 QA

只有全部硬门槛通过，才把图片报告为最终交付。

## 身份

- [ ] 与 `../assets/juanjuan-character-reference-v3.png` 是同一个可识别角色。
- [ ] `character-dna.md` 中每个身份不变量都成立，没有重新设计角色。
- [ ] 没有把卷卷描述成现实儿童、固定性别或视觉中性角色。

## 来源事实

- [ ] 画面只表达来源事实卡中的 `core_claim`。
- [ ] `exact_terms`、`required_relationships` 和 `required_counts` 与原文一致。
- [ ] 没有画入 `unsupported_inferences` 或正文没有支持的象征关系。
- [ ] 专业内容可以从画面反查到对应的原文判断。

## 动作与关系

- [ ] 卷卷完成提示词指定的精确动作，没有被简化成站立、指向或拿着道具。
- [ ] 指定的手、脚或身体部位真实接触对应物件。
- [ ] 物件数量逐项正确，没有合并、缺失或增加。
- [ ] 同类匹配、不同类隔离、先后与方向逐项正确。
- [ ] 每条路径都能从起点连续追踪到终点，没有遮断或错误分叉。
- [ ] 去掉卷卷后，画面不再完整成立。

## 画面

- [ ] 横版比例与 16:9 的误差不超过 1%。
- [ ] 暖奶油纸面、铅笔、彩铅、蜡笔和淡水彩质感清楚。
- [ ] 默认只有一个焦点动作，并使用非对称景深和自然留白。
- [ ] 除非用户明确要求，没有左—中—右讲解板、PPT 卡片、规则网格、密集箭头或教学信息图感。
- [ ] 角色与物件没有错误肢体、穿插、裁切或比例突变。

## 文字

- [ ] 只出现来源事实卡 `allowed_labels` 中的字符，没有额外标题、解释或装饰字。
- [ ] 保留来源的繁体、简体或混合书写方式，没有自行转换。
- [ ] 所有文字逐字核对，没有错字、乱码、遮挡、裁切、签名或水印。
- [ ] 关键文字采用“无字底图 → 局部加字 → 逐字核对”的流程。

## 权利与交付

- [ ] 未宣称角色已完成原创、商用清权、法律审查、受众测试或最终母版确认。
- [ ] 面向公开发布、授权、商品化或公开再分发时，已提醒来源与权利仍待确认。
- [ ] 图片和同名 `.prompt.md` 均已保存，记录包含来源事实卡、最终提示词、工具、QA、迭代和路径。
- [ ] `scripts/validate_artifact.py` 对最终图片返回退出码 0。
- [ ] 只报告实际生成并保存的文件，没有覆盖用户已有资产。

## 失败恢复

- 身份漂移：从角色参考图重生成整张，不以漂移结果继续派生。
- 来源失真：回到原文重做来源事实卡，再重写隐喻与提示词。
- 动作简化：把身体部位、接触对象和动作结果写成硬约束后重生成。
- 数量或路径错误：删除非必要元素，逐项列出精确数量和起终点后重生成。
- 太像 PPT：移除讲解板、卡片、规则网格和对称布局，改成单一物理场景。
- 文字错误：少量错误局部编辑；错误较多时回到无字底图并逐个加字。
- 风格幼儿化：保留绘本媒介，但加入承压青年能识别的疲惫、克制或轻微自嘲。
