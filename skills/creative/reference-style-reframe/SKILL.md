# 多风格图文重构

将用户有权使用的参考图，转为结构更简洁、风格明确的图文插画。保留的是可观察到的题材、主次关系、构图比例、整体色彩调性与支撑识别的中层细节；不是复制原图的笔触细节、签名或作者识别特征。

只在用户显式调用 `$reference-style-reframe` 时执行本 Skill。

## 开始前

1. 必须查看实际参考图。网页链接无法读取清晰画面、只有口头描述或只给风格文案时，说明缺少参考图；可以给可填模板，但不得声称已完成“根据原图”的重构。
2. 提取一张**画面取证卡**：原始比例、主体与主次关系、主体位置、远近层次、2–4 个 **P0 核心结构**、0–5 个 **P1 识别细节**、2–5 个综合色组、**P2 可删项**、`style_profile`、`style_intensity`、`scene_mode`，以及文字的确切内容或 `none`。P0 是缺失后场景会变样的结构；P1 是支撑识别的中层细节；P2 仅包含未列入 P0/P1 的微纹理、杂物和厚重光影。除非数量本身有识别意义，不要把普通细节强行编成精确数量。
3. 用户只要方案或提示词时，不生成图片。需要生成但没有可用图像工具时，交付可执行提示词和工具阻塞，不虚构图片或路径。
4. 用户没有给出英文标题和短句时，不编造英文标题。用 `text_area` 决定版面：两段精确英文都已提供时，默认 `reserved`；用户明确要求预留排版区时用 `reserved`；用户明确要把文字叠入现有留白时用 `overlay`；其余情况默认 `none`，只生成无字底图，不额外切出底部文字带。
5. 参考图来自第三方、公开账号或品牌时，不要保留或复刻签名、水印、Logo、可识别角色或受保护的独特表达。公开发布或商业使用前，提醒用户确认参考图与改编链路的权利；不得作出清权、原创或商用安全承诺。

## 选择风格档案

可用档案为 `ink-wash-flat`、`gongbi-traditional`、`gouache-matte`、`paper-collage`、`soft-pastel`、`linocut-editorial`、`risograph-editorial`、`colored-pencil-storybook`、`folk-papercut` 与 `minimal-vector-poster`。用户指定其中之一时照选；未指定时默认 `ink-wash-flat`，保持旧调用的水墨行为。用户给出非作者化的风格描述时，可归入最接近档案并说明映射；不要擅自混用两个档案，也不要按在世或可识别作者、品牌、IP 的独特风格仿作。

`style_intensity` 为 `restrained`、`balanced` 或 `pronounced`：用户未指定时用 `balanced`；要求更贴近原图时用 `restrained`；明确比较档案差异或要求更强风格化时用 `pronounced`。强度只控制材质、边缘、色层与 P2 的简化程度，不能删除 P0/P1 或改变构图关系。

读取 [风格档案](references/style-profiles.md)，只取所选档案的 `Prompt addendum` 与对应 QA 条目。不同档案可改变纸张、色层、边缘与纹理预算，但不能改变 P0/P1、比例、构图关系、`text_area` 或权利边界。

遇到车轮辐条、砖缝、密集枝叶、栏杆或重复瓦片等复杂 P1 时，读取同一参考中的“复杂 P1 转写”，只保留轮廓、方向和少数识别节点；重复细线归入 P2，除非已明确列为 P1。

## 选择场景路由

`scene_mode` 默认 `standard`，沿用原有风景、建筑、静物和轻叙事流程。出现以下情况时，选择对应路由并读取 [场景路由](references/scene-routes.md) 的单个章节：

- `portrait-figure`：一至三名人物是画面主体，需保留人数、位置、姿态、朝向与服饰色组。
- `product-still-life`：一个或多个实物商品是主体，需保留数量、轮廓、可见组成和摆放关系。
- `dense-narrative`：多人、多物或多区域共同构成叙事，删减会改变事件或空间关系。

场景路由只增加取证与 QA，不替换 `style_profile`，也不能放宽 P0/P1、精确文字、权利或技术图边界。人物身份、商品品牌与密集场景中的微小对象都不得由模型猜测或补造；参考图无法支撑所需辨识度时，说明限制并请用户标出优先保留项。

## 测试风格横向对照

仅当用户明确要求比较风格，或正在评估/修订本 Skill 时，执行一次**完整档案横向对照**：以同一张参考图、同一份画面取证卡、同一个 `text_area`、相同的 `scene_mode`、完全相同的 P0/P1/P2 与 `style_intensity=pronounced`，同时生成 `ink-wash-flat`、`gongbi-traditional`、`gouache-matte`、`paper-collage`、`soft-pastel`、`linocut-editorial`、`risograph-editorial`、`colored-pencil-storybook`、`folk-papercut` 与 `minimal-vector-poster` 十张无字图。逐张标明档案名，再检查每张的结构保留、P1 可辨性、所选档案的标志性材料，以及是否混入其他档案。

横向对照只验证同一题材中的档案区分，不能替代每档适配题材的视觉验证。测试时读取 [视觉测试矩阵](references/visual-test-matrix.md)，另用其中的适配题材检查该档案的核心技法。不要把完整档案横向对照用于普通的单档交付，也不要为凑齐风格而使用不同参考图、改变取证卡或添加画外元素。测试发现的问题按“一个档案、一个失败项”单独返工。

## 重构流程

### 1. 固定不能漂移的画面事实

先用画面取证卡约束比例、主体关系、空间层次、P0 核心结构与综合色组。P0 必须完整保留；P1 必须逐项可辨，例如屋檐节奏、门框与台阶、桥面砌块分组或水面的主要倒影带。P1 可改为低对比小块面、断续淡墨或不规则色组，不能因“简化”被抹成单一轮廓。P2 才可删去枝叶、路牌、人流、随机反光和噪点，但不要把建筑、山水、道路或水面等 P0 结构换成无关场景。

### 2. 先完成无字底图

读取 [提示词与质检模板](references/prompt-and-qa.md)，将事实卡和所选档案填入“无字底图模板”。其硬约束是：

- 所选档案的材质、色层、纹理和边缘规则必须同时出现；不要把水墨晕染、纸边、粉尘或版画刻线漏到未选择的档案中。
- P0 可用所选档案允许的主要轮廓或层次表达；P1 必须独立可辨，且遵守该档案的次要细节和边缘预算。禁止无依据地给所有物体普遍描边。
- 不使用写实厚光影、P2 之外的密集微纹理、杂物或装饰边框；风格化不能掩盖 P0/P1。
- `standard` 场景在不与原图关键关系冲突时，将主体置于居中偏上。使用人物、产品静物或密集叙事路由时，优先保留取证卡记录的原图位置、相对关系或事件分区；不得为了“居中偏上”而重排、裁掉或合并人物、产品或场景分区。`reserved` 时保留干净、低对比、无物体遮挡的文字安全区；`overlay` 时只在已有安静留白中排版且不压住 P0/P1；`none` 时不人为保留底部安全带。留白是构图的一部分，而不是背景空缺。
- 依参考图的综合色组建立调色，而不是强行套用青绿、黑白或“国风”符号。

### 3. 以可验证方式加入文字

对要逐字正确的标题，采用**无字底图 → 后期排版 → 逐字核对**。后期排版时，首行使用用户已授权或可用的优雅衬线/手写感英文字体，第二行使用小号无衬线英文短句；`reserved` 放在预留区，`overlay` 放在确认过的现有留白。没有用户提供的文案时保持无字，不用占位乱码。

若用户坚持在图像生成阶段直接出字，先明确这不能保证拼写；输出后逐字检查，错字、乱码、文字遮挡或缺字即退回无字底图再排版。

### 4. 质检与单变量返工

按模板和所选档案的 QA 门槛检查。一次返工只改一个失败项：P0 失真时回到事实卡；P1 丢失时只补回缺项，并保持档案允许的细节表达；边缘或纹理越界时只恢复所选档案的预算；文字区挤压画面时重选 `text_area`；文字错误时回到无字底图。未实际查看、生成或检查的部分必须如实标为未验证。

## 交付

交付提示词、画面取证卡、文字排版规格和 QA 结果；已生成时再报告实际文件路径与所用工具。不要覆盖已有资产，除非用户明确要求替换。

## 任务边界

- 适合旅行照片、风景、建筑、静物和轻叙事照片的水墨、工笔、水粉、拼贴、粉蜡笔、版画、套色网印、彩铅、剪纸或极简矢量图文重构；人物、商品与高密度叙事须使用对应场景路由。
- 不用于需要精确尺寸、可编辑节点与连线的工程图、信息图、准确产品规格或电商主图，或要求复刻某位作者、品牌/IP、现有作品的独特画面。
- 不把“水墨”“学术感”误解为添加印章、诗句、题跋、书法、边框或泛化中国元素；除非用户明确提供并允许这些内容。
