# 视觉测试矩阵

仅在评估或修订 Skill 时使用。测试图必须来源清晰、可使用，且每次记录同一份画面取证卡、`style_profile`、`style_intensity`、P0/P1/P2 与观察结论。模型输出是否合格必须看图判断；行为 fixtures 只验证决策文本，不能验证像素。

## 两层测试

### 1. 同图横向对照

使用一张包含明确近景、中景、远景和一个复杂 P1 的建筑或街景，固定 `style_intensity=pronounced`，一次生成全部十档。它只检查：P0/P1 是否同时保留、档案是否容易区分、是否出现档案串味、复杂 P1 是否被线稿化。

### 2. 档案适配题材

每档另选一种更能显出其核心语言的测试图。不可用横向对照结果替代这一项。

| 档案                       | 建议固定题材                         | 必须观察                       | 常见失败                         |
| -------------------------- | ------------------------------------ | ------------------------------ | -------------------------------- |
| `ink-wash-flat`            | 河道、桥、远山与岸屋                 | 大留白、稀疏淡墨、松散色块     | 稠密水彩或泛化国风装饰           |
| `gongbi-traditional`       | 园林、荷花、鸟、器物或细部建筑       | 均匀细线、薄矿物设色、分染层次 | 泼墨、题跋、印章或仿古复制       |
| `gouache-matte`            | 明确色块的街景或静物                 | 不透明哑光色层、干刷分隔       | 高光塑料感或透明水彩             |
| `paper-collage`            | 建筑、静物、简洁叙事                 | 平面纸层、纸边、低阴影         | 立体纸雕、胶带或杂乱拼贴         |
| `soft-pastel`              | 傍晚风景、室内静物或季节场景         | 粉性大色团、揉擦过渡           | 铅笔线稿、喷枪感或脏灰噪点       |
| `linocut-editorial`        | 植物、山野、桥或建筑                 | 有限色、定向刻线、留白         | 满版密刻线或所有 P1 都被黑线包住 |
| `risograph-editorial`      | 色块明确的街景、海报感静物或旅行物件 | 2–4 色套印、粗颗粒、轻微错位   | 数码渐变、满版噪点或写实阴影     |
| `colored-pencil-storybook` | 花园、室内生活、动物或轻叙事场景     | 可见定向彩铅、柔和色层、纸白   | 粉彩涂抹、蜡笔蜡感或写实素描     |
| `folk-papercut`            | 花果、鸟兽、门窗或民居剪影           | 镂空关系、实色剪影、有限色     | 无关吉祥纹样、红色填满或 3D 纸雕 |
| `minimal-vector-poster`    | 建筑、山海、器物或明确主体关系       | 少量几何形、干净色块、清晰留白 | 纸张肌理、笔触、渐变或普遍描边   |

## 场景路由测试

每条路由另选一种不与前述建筑、园林或静物测试重复的参考图，并一次生成至少五个不同 `style_profile`。同一轮中固定画面取证卡、`scene_mode`、P0/P1/P2、`text_area` 与 `style_intensity=pronounced`；逐张检查路由不变量，不能因风格不同而放宽。

| 场景路由             | 建议固定题材                               | 必须观察                                                    | 常见失败                                                       |
| -------------------- | ------------------------------------------ | ----------------------------------------------------------- | -------------------------------------------------------------- |
| `portrait-figure`    | 一至三人的日常场景或半身环境肖像           | 人数、位置、姿态、朝向、服饰色组与手势不漂移                | 凭空换人、增减人物、改动作、补饰品或将脸部写实化               |
| `product-still-life` | 无品牌器物、家居物件或包装外观干净的商品   | 数量、轮廓、可见部件、材质色组与摆放关系                    | 改产品结构、增加功能件、编造品牌/标签或做成电商规格图          |
| `dense-narrative`    | 有明确事件关系的市集、餐桌、教室或家庭活动 | 事件区、主体数量、关键动作、前中后景与用户指定的 0–5 个细节 | 人群融化、增减主体、关键动作丢失、所有区域同等细化或凭空补剧情 |

## 记录格式

每次至少记录 `profile / source suitability / P0 / P1 / must appear / must avoid / pass or one failure item`。若失败，只按该档案的一个失败项返工后再检查；不要同时更换题材、结构卡和风格强度。
