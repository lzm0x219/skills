# 场景检查

仅阅读当前涉及的分支。每个分支先确定语义和硬约束，再比较简单基线与候选；执行授权遵循 `SKILL.md`。

## 缓存：容量、时效与并发

- 分开定义容量淘汰、TTL 到期与业务失效；TTL 限制存活时间，不限制突发写入的内存，LRU 也不保证内容新鲜。
- 值大小不同时按字节预算，计入 key、value、索引／链表元数据、过期索引和在途加载。超过单条预算的值选择拒绝缓存或直接返回；不能靠淘汰其他条目装入超限对象。
- 先比较不缓存与现成有界缓存；需要自实现 LRU 时说明 map 与顺序结构的一致性。LRU 命中会更新顺序，属于写操作。
- 同键回源合并与缓存失效分别设计；旧加载完成后不能覆盖较新的值或让已失效数据复活。用版本或 generation 校验，并为失败／取消清理在途状态。
- 验证：容量为零、超大值、替换大值、同刻过期、并发同键加载，以及“开始加载 → 失效 → 旧加载返回”。验收内存预算和新鲜度，不只看命中率。

## 依赖图：完整性、方向与确定性

- 明确节点 ID、边的方向、重复边与缺失依赖的处理。例如 `A depends on B` 表示调度边 `B → A`，同时维护出边与入度。
- 执行前验证缺失节点、自依赖与环。Kahn 处理数少于节点数可识别存在环，但剩余节点也可能只是被环阻塞；用 DFS 或强连通分量给出实际环见证。
- 要求“有环时任何任务都不执行”时，先验证整图再调度；不能边执行无环部分边发现其余环。
- 可同时执行的节点若需稳定顺序，明确排序键与 tie-break。普通队列拓扑排序是 `O(V + E)`；用最小 heap 保证按 ID 选取时，通常为 `O(E + V log V)`，空间 `O(V + E)`。
- 验证：链、菱形、孤立节点、重复边、缺失依赖、自环、环及下游节点；检查每条依赖先于使用方，改变输入枚举顺序仍满足约定。

## 数据超出内存：精确性与外存

- 区分 RAM、临时磁盘、最终存储和 I/O 预算。流式读取不代表中间状态有界；精确 set 仍随唯一键数量增长。
- 精确去重先比较数据库唯一索引与外部排序归并。后者按字节切块，限制归并路数和文件句柄，必要时多轮归并；计入最大记录、缓冲和序列化开销。
- hash 分区需要处理倾斜与单个分区超内存；不能假定所有分区均匀。输出需保留首次出现顺序时，额外保存序号并计入恢复顺序的成本。
- Bloom filter 只作预筛，阳性需查精确存储；要求零漏项时，不能直接丢弃所有阳性输入。磁盘也不可用且输入唯一键无界时，说明精确结果与固定内存冲突，提出可选约束变化，不暗改为近似结果。
- 验证：跨块重复、相同 hash／热点分区、单条超限、空输入、磁盘不足与中断后的临时文件处理。小样本与内存精确基线比较结果集合及约定顺序。

## 并发共享状态：原子性与过载

- 先确定单线程／多线程、跨进程与一致性要求；线程安全容器不能自动保证“检查 → 更新”整个业务操作原子。
- 先比较单所有者加有界队列、锁保护的标准集合与现有并发集合。分片改变容量统计和跨键操作成本；无锁需要内存序、回收和 ABA 等额外论证，不因“并发”二字自动推荐。
- 有界队列的“检查容量 → 入队”和共享配额的“检查 → 扣减”必须作为同一个原子操作。锁或原子预约能保护不变量；昂贵计算与外部 I/O 尽量在临界区外完成。
- 固定队列条目数仍需限制条目字节和在途任务。达到上限时明确阻塞、超时、拒绝或丢弃策略；取消、异常、关闭必须释放预约并唤醒等待者。
- 验证容量只剩 1 时两个生产者竞争、消费与关闭交错、取消和重复完成；验收容量不超限、每项至多处理一次或明确的重试语义，以及无死锁。用可控交错核验不变量，吞吐压力测试不能替代正确性检查。

## Top-K：分数、频次与过期

- 先定义排名对象：记录的 score，还是 key 的累计频次；再定义 K、同分顺序、精确性、窗口边界、时间来源及迟到／更新／删除策略。
- 无过期且得分不变的记录流，可以用大小为 K 的 min-heap；处理 N 条记录为 `O(N log K)`、额外空间 `O(K)`，加上单条记录或引用的大小。
- 频次 Top-K 的精确计数表占 `O(U)`，U 为唯一键数。Count-Min Sketch／Space-Saving 处理频次统计，不能直接替代按任意记录得分排序。摘要的候选枚举、误差和窗口删除能力需要分别说明。
- 有过期时，丢弃当前 Top-K 之外的记录前证明它以后不会成为答案。固定桶摘要适用于完整桶；任意时刻的精确滚动窗口需要处理部分边界桶，分钟桶边界误差不能称为精确。当前完整桶以后也会成为边界桶，所需原始数据必须保留或可从外存恢复，不能只保存当前边界桶的数据。
- 验证“较高分记录先过期、较低分记录仍有效”、同分记录、边界时刻、迟到、分数更新和空窗口；与按同一窗口过滤后全量排序的基线逐次比较。

## 测量与停止条件

只有性能影响本轮选择时才运行基准。先验证结果等价，记录输入规模与分布、操作比例、硬件／运行时版本、基线、预热和重复次数；随机生成输入时固定种子。根据目标报告延迟 median／P95、吞吐、峰值内存或 I/O，统计口径一致。

分布至少包含与当前风险直接相关的倾斜或边界；不为覆盖所有可能输入扩展测试。区分理论复杂度、单次观察与重复测量，不能把 `O(1)` 宣称为固定耗时，或把无数据的预计提升写成实测收益。

结果不等价、违反硬约束或测量推翻建议时重开决策；适用正确性检查与项目必需检查通过，且剩余性能不影响选择时停止。没有运行的检查明确列为未验证。
