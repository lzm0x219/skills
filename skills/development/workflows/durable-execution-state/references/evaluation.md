# 评测协议

仅在评测本 Skill、比较实现或声称长程收益时读取。协议层正确性、模型行为和论文级伸缩结论是三类不同证据，不能相互替代。

## 离线协议回归

通过 `statectl.py` 的公开 CLI seam 验证：

- 连续 100 次以上局部转换后，`state_version`、最终状态和事件重放一致；
- 状态字节数保持在配置预算内，原始观察只留下稳定引用；
- 相同动作重试不增加 action/event，冲突请求被拒绝；
- commit 前故障回滚，commit 后响应丢失可经版本或幂等键恢复；
- 并发读写下 `verify` 只比较同一 SQLite 快照，不产生混合视图误报。

这类测试证明协议与存储实现，不证明模型在真实长程任务中会正确维护状态。

可运行 `scripts/rehearse_recovery.py --steps 100`，它调用公开 CLI，在临时目录验证回滚、已提交动作恢复、snapshot 重建和回执重试。示例不运行外部执行器，也不验证真实宿主授权；详细步骤见 [宿主接入与恢复](host-integration.md)。

测量前记录修订、Python／操作系统、步数和重复次数。脚本输出 CLI patch median/P95（包含进程启动）、重放耗时、事件数、补丁阶段峰值序列化状态字节数与最终状态大小。单次运行是本机协议基线，不能当作模型收益或进程峰值内存；比较修改前后性能时使用同机、同输入与相同计时范围，至少重复三次。只有出现实际瓶颈时才扩展规模或设计 checkpoint。

## 模型行为回归

至少覆盖：恢复、过时事实与当前事实冲突、噪声观察、部分副作用、上下文压缩后的继续执行。固定 fixture 只验证评测运行器；模型质量必须用无 `--answers` 的 live run 判断，并保存模型版本、推理强度、日期、每项原始输出和重复次数。

额外检查：状态维护无需验证器、Agent 自建验证器不能建立宿主信任、已登记动作不等于再次派发、提交后失败先对账、内部 verify 不证明外部事实，以及演练指标不能当作 `O(1)` token 证据。单轮回答只能覆盖这些决策；真实跨会话恢复还需要宿主控制中断与历史注入。

## 论文级比较

若声称接近论文的长程伸缩收益，使用相同任务与模型做成对比较：基线保留普通会话历史，实验组由宿主每轮只注入指令、当前有界状态和最新观察，并丢弃旧推理。至少测量成功率、prompt tokens、completion tokens、延迟、状态字节数、事件数和方差。

纯 Skill 不能控制宿主历史注入或删除，因此没有这个运行时对照时，只能报告“显式状态协议已验证”，不能报告 `O(1)` prompt、token 降低或长程成功率提升。
