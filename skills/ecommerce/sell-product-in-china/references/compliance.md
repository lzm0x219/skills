# 中国电商合规分流

## 目的

在生成可公开使用的商品页、价格、图片或社媒内容前，确认哪些事实能够表达、哪些规则必须实时核查、哪些缺口会阻止「可直接上架」交付。本文件是工作流检查表，不替代品牌方或专业人员的法律审核。

## 基础事实门

先记录并区分「已核实／待核实／不适用」：

| 范围       | 最低事实                                                     |
| ---------- | ------------------------------------------------------------ |
| 商品身份   | 品牌、准确 SKU、类目、销售单元、规格、产地与责任主体         |
| 标签与证明 | 包装标签、成分或材质、许可证、认证、检测与授权文件           |
| 宣称       | 功能、功效、数据、排名、奖项、用户评价与比较对象             |
| 交易       | 人民币价格、税费、库存、履约、退换、赠品与促销条件           |
| 素材权利   | 商品图、Logo、字体、人物肖像、评论截图和第三方内容的使用范围 |
| 发布环境   | 成交平台、流量渠道、商业内容标识和目标受众                   |

没有资料支持的奖项、销量、功效、认证、稀缺性、原价、倒计时、用户身份和排他性结论一律不得补写。

## 高风险品类

遇到以下品类时，将合规核查设为发布前硬门槛：

- 食品、酒类、保健食品和膳食补充相关商品；
- 化妆品、个护产品及任何功效宣称；
- 药品、医疗器械、健康监测与疾病相关商品；
- 母婴、儿童、教育及面向未成年人的商品；
- 带有环保、原产地、专利、认证、排名或比较性宣称的商品；
- 使用人物肖像、用户评价、达人内容或第三方品牌资产的商品。

对高风险品类：

1. 只从当前官方监管、平台规则和用户提供的有效证明确认硬事实；
2. 记录来源 URL、规则或材料名称、访问日期和适用范围；
3. 将「商品事实」「允许表达」「禁止或待审表达」分别列出；
4. 关键资料缺失时继续完成内部战略假设，但对外文案使用明确占位符，并把发布状态标成 blocked；
5. 不把常识、竞品文案、社媒说法或模型记忆当成合规结论。

## 平台可上架门

只有用户要求某平台可直接上架时，才核查该平台当前的类目准入、字段、标题、图片、价格、促销、履约和商业内容标识。规则可能变化，必须优先使用平台当前官方页面；无法访问或无法确认时，交付平台适配草案和待核清单，不声称已经合规或可以发布。

## 输出

在 `internal/research-audit.md` 中增加：

```text
category_risk: normal | high
verified_facts:
allowed_claims:
blocked_claims:
rights_status:
current_rule_sources:
publication_blockers:
review_owner:
```

最终素材清单必须把未核实宣称、缺失标签、素材授权和平台规则分别列为「待客户补充」或「发布阻塞项」。
